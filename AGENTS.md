## Clarifying Questions

- If the user's prompt is unclear, ask concise follow-up questions before making
  meaningful code, design, architecture, or business decisions.
- Prefer 1-3 specific questions that unblock the work.
- When a safe default is obvious, state the assumption and proceed; when the
  wrong assumption could waste time or create rework, ask first.
