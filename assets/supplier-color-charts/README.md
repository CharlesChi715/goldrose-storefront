# Supplier colour charts

Photographs of the supplier's printed colour charts for the style-B gold-dipped
rose, one per series: classic (`Y`), colourful (`YC`), star glitter (`YS`).
13 MB of originals — what the supplier actually sent. Never served; Next.js
only serves `public/`.

`docs/supplier-color-charts.md` transcribed them into a table. PR #61 deleted
that transcription on 2026-09-21, because it restated the images and had
drifted from them. Read it from history if the table is wanted again:

    git show af211fb^:docs/supplier-color-charts.md

No code reads these files and no colour in the catalogue is generated from
them. They are the reference to check a product's colour wording against, and
the record of what was on offer when the range was chosen.
