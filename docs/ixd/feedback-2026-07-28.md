## English

Hi team — the 07-28 delivery (ACCOUNT-PRIVACY-SUPPORT, 10 frames) is
imported and live on our preview. Everything rendered pixel-exact. A few
items only you can resolve:

1. **Duplicate frame.** `ACCOUNT-PERSONAL-INFO-DETAILS-ALT` (1232:114) is
   byte-identical to `ACCOUNT-PERSONAL-INFO-DETAILS` (1230:112) — every
   node matches. We imported it once; please delete the duplicate, or make
   it the variant it was meant to be.

2. **Password + two-step verification conflict.** The security screen
   designs password change and 2FA, but customer sign-in is decided as the
   emailed sign-in link (code fallback) — accounts have no password. This
   is the second occurrence (AUTH-SIGNUP had password fields on 07-27).
   The fields ship as non-interactive visuals for now; please redesign the
   security screen around the emailed-link flow before we wire it.

3. **Bottom navigation — please settle one design.** The file now contains
   three different bottom-nav languages: the owner-art bar (home/shop), the
   CARE 32px glyph band with an active pill, and this batch's new 72px
   glyph band without a pill — while three of the new screens (returns,
   chat, keepsake) have no nav at all. Also the account tab has switched
   between "Login" and "Me" four times across revisions ("Me" is live).
   One decision here unblocks a lot of consistency work.

4. **Mock-data details to fix at source** (shipped verbatim as visible
   mocks): the security screen shows a session in "Tokyo, JP" on a
   "GoldRose App" (the store targets the US and there is no app); the
   returns screen uses 2025 dates; the chat's order #GRB-20260821 ships
   "May 18–23"; the keepsake card says "Purchased on: Aug 21, 2026" —
   a future date.

5. **Carry-overs still open from earlier batches:** the B-1 "Personal
   Card" add-on still shows a boxed rose set (the other half of the swap
   was fixed); mascot artwork still needs true transparent PNGs (alpha,
   no baked checkerboard); PDP-MEDIA still needs the uncropped source
   imagery; CARE's Hot-topics tab still omits the "Support request
   status" row the other three tabs have — confirm if intended.

Thanks — the new screens look great on the preview site.
