## Known inconsistencies in the source

Recorded here as observations about the transcription; the fixes live in
[element-names.md](element-names.md).

1. **Two examples use TYPE words absent from Sheet 4** — `PDP-PRODUCT-PRICE`
   (`PRICE`) and `PDP-COLOR-OPTION` (`OPTION`).
2. **Two words appear in two dimensions at once** — `MEDIA` and `DRAWER` are
   each both a SECTION (Sheet 2) and a TYPE (Sheet 4).
3. **No rule for repeated elements** — `SHOP-PRODUCT-CARD` names a type, so
   every card in a grid shares one name.
