## 订单详情页 / 礼物配送分享

### ORDER-DETAIL-SHARE-TRACKING · 次级功能卡片

| 字段 | 内容 |
|---|---|
| 元素类型 | 次级功能卡片 |
| 布局属性 | 横向通栏卡片；左侧GIFT标签；中部标题与说明；右侧箭头 |
| 是否可点击/操作 | 是 |
| 触发方式 | 点击卡片或右侧箭头 |
| 跳转/触发结果 | 生成收件人专属物流链接，并调起系统分享面板 |
| 目标页面/界面 | Gift Tracking分享界面 / 系统分享面板 |
| 状态与反馈 | 生成中、分享成功、复制成功、生成失败；暂无物流时禁用并提示 |
| 开发备注 | 链接使用只读安全Token；仅显示物流进度和预计送达时间，隐藏价格、付款方式及完整地址；支持链接失效和撤销 |
| 目标页制作情况 | 待确认 |
| 修改 | 建议整个卡片可点击，并提供“Copy Link”快捷操作 |

## 订单详情页 / 订单帮助

### ORDER-DETAIL-CONTACT-SUPPORT · 客服入口卡片

| 字段 | 内容 |
|---|---|
| 元素类型 | 客服入口卡片 |
| 布局属性 | 横向通栏卡片；左侧HELP标签；中部标题、说明与文字链接 |
| 是否可点击/操作 | 是 |
| 触发方式 | 点击卡片或“CONTACT SUPPORT” |
| 跳转/触发结果 | 携带当前订单信息进入客服渠道选择或在线客服 |
| 目标页面/界面 | Customer Care / Contact Support |
| 状态与反馈 | 显示客服在线状态、连接中、消息发送成功及连接失败反馈 |
| 开发备注 | 携带 orderId 和订单状态；自动预填问题上下文；隐藏敏感支付信息；非服务时间显示预计回复时间 |
| 目标页制作情况 | 待确认 |
| 修改 | 建议整个卡片可点击，并增加“Online now / Reply within 24h”等服务状态 |
